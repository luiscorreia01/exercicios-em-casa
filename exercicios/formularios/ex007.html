Atributos para formulários


Usando os atributos REQUIRED, AUTOCOMPLETE, MINLENGTH, MAXLENGTH, PLACEHOLDER E SIZE


REQUIRED - usar para deixar o preenchimento dos campos obrigatórios, para que seja enviado ao php (ou outra linguagem escolhida)

AUTOCOMPLETE - deixar a opção "on" dentro da tag "form" permite que na tag "input" se indique o autocomplete e estabeleça um link com o navegador

MINLENGTH e MAXLENGTH - Usados para definir o número mínimo e máximo de carcteres/letras permitidos dentro de cada caixa (Devem ser configurados dentro da tag "input")

PLACEHOLDER - Permite colocar uma "dica" dentro das caixas. (Deve ser configurado dentro da tag "input")

SIZE - Utilizado para alterar o tamanhodas caixas. Esta confuguração é utilizada dentro do HTML.(Deve ser configurado dentro da tag "input")
